Forgot your password, or never set one

  1. On the sign-in page press Forgot password?
  2. Enter your user ID exactly as above and press E-mail me a code. Within seconds an e-mail "Marikar hub: choose a new password" arrives (check Spam or Junk too).
  3. Take the 8-character code from that e-mail, like K7QM-3XPA. Always use the newest e-mail: each new code cancels the earlier ones.
  4. On the sign-in page, type the code and your new password twice (at least 10 characters, letters plus a number or symbol, not your user ID). Press Set my password.
  5. Wait a few seconds for "Your password is live", press Sign in, and sign in with the new password.
